# 🏏 IPL Win Predictor - Machine Learning Project

This project is a machine learning-based web application that predicts the winning team of an IPL (Indian Premier League) cricket match based on current match data such as team names, toss result, and venue.


---

## 🚀 Features

- Predicts the winner of an IPL match using match context.
- Takes into account:
  - Batting team
  - Bowling team
  - City (Venue)
  - Current runs, wickets, overs
  - Target score
- Clean and interactive user interface using **Streamlit**.

---

## 🧰 Tech Stack

- **Python**
- **Pandas**, **NumPy**
- **Scikit-learn**
- **Streamlit** (for the frontend)
